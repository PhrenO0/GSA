> 출처: [케로 NOTE] GPT로 만드는 핀터무드 이미지 프롬프트 모음.zip (@case.zero.note)

> 원문 프롬프트 11종을 역설계해 구조·규칙·빈 양식으로 정리한 문서.
> 원본 프롬프트를 그대로 재가공해 배포하지 말 것 (작성자 요청). 이 문서는 "만드는 원리"만 추출.

## 0. 원작자가 밝힌 전제 3가지

1. GPT처럼 **LLM을 끼고 있는 이미지 생성 모델**은 이미지의 모습을 상세하게 설명할수록 원하는 결과에 가까워진다.
2. **한글 프롬프트로 써도 잘 나온다.** (LLM 베이스 모델은 영문 프롬프트가 굳이 필요 없음)
3. 워크플로우는 **"AI로 초안 → 소품과 포즈를 사람이 수정"**. 프롬프트는 한 방에 쓰는 게 아니라 고쳐 쓰는 것.

## 1. 이 프롬프트들을 관통하는 핵심 원리 6가지

### 원리 1 — 얼굴을 반드시 가린다 (익명성 = 무드 + 안전장치)
11개 전부 얼굴이 온전히 보이지 않는다. 수단은 매번 다르다:

| 방식 | 사례 |
|---|---|
| 프레임 아웃 (1인칭 POV) | 01 컵캐리어, 06 1인칭 카페 |
| 폰이 얼굴을 가림 | 02 쇼윈도 반사, 11 서로찍기 |
| 모자 챙 그늘 | 04 하이앵글 연석 |
| 선글라스 | 05, 07, 09, 10, 11 |
| 턱 아래부터 크롭 | 10 용과 리프레셔 |

이유는 두 가지다. ① 핀터레스트 특유의 "누구든 될 수 있는" 무드. ② AI가 가장 잘 망가뜨리는 부위가 얼굴이라, 애초에 안 보이게 하면 실패율이 급락한다. **새 프롬프트를 만들 때 얼굴 처리 방식부터 정하는 게 순서상 맞다.**

### 원리 2 — 저채도 베이스 + 채도 높은 포인트 1~2개
팔레트 문장이 11개 중 10개에 거의 동일한 공식으로 들어간다:

> 팔레트는 **[주조색 2~3]** 주조에 **[포인트색 1~2]** 포인트, **[보조색]** 보조, **중저채도**.

주조는 늘 무채·뉴트럴(그레이 아스팔트, 스톤 베이지, 크림, 화이트)이고, 포인트가 시선을 잡는다 — 우베 라떼의 라벤더 퍼플(01), 레드 페이턴트 백(02), 말차 그린(03), 연초록 캡(04), 패러킷 그린 카세트백(06), 마젠타 용과(10). **포인트를 3개 이상 넣으면 이 무드가 깨진다.**

### 원리 3 — 물리 법칙을 문장으로 강제한다 (실패 모드 선제 차단)
이게 이 프롬프트들이 일반 프롬프트와 갈리는 지점이다. AI가 틀릴 걸 미리 알고 못 박는다:

- 형태 붕괴 차단: `전체 윤곽은 모서리가 둥근 정사각형으로 **찌그러지거나 뒤틀리지 않은** 반듯한 형태다` (01 컵캐리어)
- 금지 지정: `평평한 플랫 뚜껑(**돔 뚜껑 금지**)` (03)
- 오답 지정: `화이트 NY 로고 자수가 박혀 있다(**LA가 아니라 반드시 NY**)` (04)
- 부양 차단: `선글라스는 **공중에 떠 있지 않고** 손가락과 맞닿아 걸려 있다` (10)
- 하중 성립: `모든 소지품의 무게가 한 손바닥과 손가락 위에 **물리적으로 자연스럽게 지지되어 어색한 부양이나 불가능한 겹침이 없다**` (03)
- 인과 설명: `**폰이 세워져 있어야 손 위 그립이 물리적으로 성립한다**` (03) — 왜 그래야 하는지 이유까지 준다
- 프레임 배제: `거울이나 창틀의 프레임·테두리는 **화면 어디에도 보이지 않고**` (02)
- 자세 모순 차단: `걸음을 내딛는 자연스러운 자세지만 **두 발 모두 발바닥이 지면에 닿아 있다**` (01)

원칙: **"안 되는 것"을 따로 몰아 쓰지 않고, 해당 사물을 묘사하는 그 문장 안에 붙인다.**

### 원리 4 — 무심함은 "정밀하게" 지시한다
자연스러움을 원하면 자연스럽게 쓰면 안 된다. 무질서를 구체적으로 설계한다:

> 트레이 위에서 소지품들은 정리되지 않은 채 무심하게 뒤섞여 있다 — 서로 아무렇게나 기대고 겹치고 비스듬히 놓여, **방금 계산대에서 쓸어 담아 나온 듯한** 자연스러움이다 (01)

`아무렇게나 굴러 있고`, `반쯤 걸쳐 있다`, `비스듬히 얹혔으며`, `자연스럽게 흩어져 있다`, `구불구불 감고 있다` — 배치 동사를 다르게 써서 리듬을 만든다.

### 원리 5 — 손은 이 작가의 시그니처 블록이다
거의 모든 프롬프트에 손 스펙이 독립적으로 들어간다. 사실상 고정 텍스트:

> 가늘고 긴 손가락의 곱고 흰 손, 매끄러운 피부, 짧고 깔끔한 자연 손톱

여기에 네일(진주빛 아몬드 / 프렌치 그라데이션 / 파스텔 팁 프렌치 / 화이트 롱), 반지 개수(`골드 링 하나뿐`, `실버와 골드 링이 섞여 두세 개`), 손목(`아무것도 차지 않았다` ↔ `가는 블랙 코드 팔찌`)을 조합한다. **개수를 숫자로 못 박는 게 포인트** — 안 그러면 AI가 손가락마다 반지를 끼운다.

### 원리 6 — 제품(PPL)은 "크기 비교 대상"과 함께 넣는다
`튜브`가 03·05·08에 반복 등장한다. 이건 광고할 화장품이 들어가는 슬롯이다. 그리고 매번 크기 기준을 옆에 붙인다:

- `튜브는 폰의 가로 폭과 비슷한 길이의 **립밤 크기**` (03)
- `튜브의 긴 변이 버터 블록의 긴 변과 **평행**하고 튜브 길이는 버터 블록보다 **짧다**` (08)

AI는 절대 크기를 모른다. **프레임 안의 다른 사물과 비교해서 알려줘야 한다.**

## 2. 프롬프트 12블록 해부

원문 프롬프트들은 예외 없이 아래 순서로 흐른다. 블록을 빼먹을 순 있어도 순서를 바꾸지는 않는다.

| # | 블록 | 역할 | 원문 예시 |
|---|---|---|---|
| 1 | **스펙 선언** | 해상도·계절·사진 장르·비율 | `초고해상도 여름 스트리트 스냅 사진, 3:4 세로 프레임.` |
| 2 | **시간·날씨·장소** | 광질의 근거를 미리 깔아둠 | `맑은 여름 한낮`, `흐린 오후 유럽풍 코블스톤 거리` |
| 3 | **시점·화각** | 카메라가 어디에 있는지 | `카메라가 거의 수직으로 내려다보는 완전한 하이앵글 탑다운` |
| 4 | **크롭·프레임 인/아웃** | 무엇이 보이고 무엇이 안 보이는지 | `얼굴은 보이지 않고, 트레이를 든 맨팔과 그 아래로 걷고 있는 다리, 아스팔트 바닥이 프레임에 담긴다` |
| 5 | **인물·포즈** | 몸의 자세 | `보도에 양반다리로 책상다리를 하고 앉아 있다` |
| 6 | **손 스펙** | 시그니처 블록 (원리 5) | `가늘고 긴 손가락의 곱고 흰 손, 진주빛 아몬드 네일에 가는 골드 링 하나뿐` |
| 7 | **소품 배치** | 사물 + 재질 + 서로의 관계 | `구겨진 종이 냅킨 위로 트레이 폭에 꽉 차게 큼직한 버터 크루아상이 반쯤 걸쳐 있다` |
| 8 | **물리 가드레일** | 실패 모드 차단 (원리 3) | `찌그러지거나 뒤틀리지 않은 반듯한 형태다` |
| 9 | **의상** | 상의→하의→신발, 소재감 필수 | `얇은 코튼 저지`, `은은한 광택이 흐르는 민트색 새틴 스커트` |
| 10 | **조명** | 광질·방향·색온도·그림자 | `한낮의 중성 백색 직사광이 트레이 위 사물들에 짧고 또렷한 그림자를 만들고` |
| 11 | **팔레트** | 고정 공식 (원리 2) | `팔레트는 크라프트 베이지·블랙 데님·그레이 아스팔트 주조에 라벤더 퍼플 포인트, 중저채도.` |
| 12 | **무드 클로징** | 반드시 `~ 무드.`로 끝 | `트렌디한 시티 걸의 여름 아침 출근길 같은 캔디드 무드.` |

**선택 블록**
- **질감·후처리** (10번에만): `과하게 선명하지 않게, 걷다가 찰나에 포착된 캔디드 스냅처럼 미세하게 부드러운 포커스와 자연스러운 필름 그레인, 손끝의 아주 옅은 모션 블러`
- **레퍼런스 참조** (10·11번): `첨부한 구도 레퍼런스와 동일한 프레이밍과 색감으로 재현한다`

## 3. 복붙용 고정 문형 사전

### 오프닝
```
초고해상도 [계절] [장르] 사진[, N:M 세로 프레임].
```
장르 실사용값: `1인칭 POV 스냅` / `반사 셀피 스냅` / `스트리트 스냅` / `셀프케어 셀피 스냅` / `매크로 클로즈업`

### 손
```
가늘고 긴 손가락의 곱고 흰 손, 매끄러운 피부, 짧고 깔끔한 자연 손톱
```

### 조명 (날씨별)
- 맑음: `한낮의 중성 백색 직사광이 [대상]에 짧고 또렷한 그림자를 만들고`
- 맑음+강한 대비: `한쪽 위에서 떨어지는 강한 백색 직사광이 [대상]에 진한 그림자를 새기는 하이 콘트라스트`
- 흐림: `흐린 날의 부드럽고 고른 확산광이 [대상]의 질감을 담담하게 드러내고 그림자는 옅다`
- 실내창: `창에서 온 밝은 확산광이 [대상]에 부드러운 하이라이트를 만들고 그림자는 옅다`

### 팔레트
```
팔레트는 [주조 2~3] 주조에 [포인트 1~2] 포인트[, [보조] 보조], 중저채도[의 맑은 톤].
```

### 클로징
```
[형용사]하고 [형용사]한 [장면 성격] 무드.
```
실사용값: `캔디드`, `무심하고 시크한`, `장난스럽고 자유로운 힙한`, `플레이풀하고 싱그러운`, `유머러스하고 트렌디한`, `여유롭고 트렌디한`, `다정하고 캔디드한`

### 가드레일 (필요한 것만 골라 해당 사물 문장 뒤에 붙임)
```
찌그러지거나 뒤틀리지 않은 반듯한 형태다
공중에 떠 있지 않고 [무엇]과 맞닿아 걸려 있다
무게가 [무엇] 위에 물리적으로 자연스럽게 지지되어 어색한 부양이나 불가능한 겹침이 없다
[A]가 아니라 반드시 [B]
[오답] 금지
프레임·테두리는 화면 어디에도 보이지 않고
[사물]은 실제 크기 그대로이며
[사물A]의 긴 변이 [사물B]의 긴 변과 평행하고 [A] 길이는 [B]보다 짧다
```

## 4. 빈 양식 (Blank Template)

각 대괄호를 채우면 그대로 프롬프트가 된다. 비워두면 앞뒤 맥락에 맞춰 기본값으로 채운다.

```
초고해상도 [계절] [장르] 사진[, N:M 프레임].
[날씨] [시간대]의 [장소],
[시점·화각 서술] — [무엇이 보이고 무엇이 프레임 밖인지].
[인물]이 [포즈·동작].
[얼굴 처리 방식으로 얼굴이 가려진다].
[손 스펙 + 네일 + 반지 개수 + 손목].
[소품 A]가 [재질·형태·브랜드]로 [배치 동사],
[소품 B]가 [소품 A]와의 관계로 [배치 동사] — [물리 가드레일].
[주력 제품]은 [프레임 내 다른 사물] 대비 [크기 관계]로 [위치].
상의는 [소재+형태], 하의는 [소재+형태], 발에는 [신발].
[조명 문장: 광질 + 방향 + 무엇을 드러내는지 + 그림자 성격].
[선택: 질감·후처리 문장].
팔레트는 [주조] 주조에 [포인트] 포인트, [보조] 보조, 중저채도.
[무드 클로징] 무드.
```

## 5. 질문 세트 (사용자에게 물을 것)

필수 4개만 답해도 초안이 나온다. 나머지는 비워두면 채워 넣는다.

**필수**
1. **한 줄 시놉시스** — 누가, 어디서, 뭘 하고 있나?
2. **주인공 소품 / 광고할 제품** — 프레임에서 제일 눈에 띄어야 할 물건은? (없으면 "없음")
3. **계절 · 시간 · 날씨** — 예: 여름 / 한낮 / 맑음
4. **컬러 포인트 1~2개** — 화면에서 튀어야 할 색

**선택 (미기재 시 자동 결정)**
5. **장소·배경** — 코블스톤 거리 / 노천 카페 / 스터코 벽 / 욕실 / 공원 …
6. **시점** — 1인칭 POV / 셀피 / 반사 셀피 / 탑다운 하이앵글 / 제3자 스냅
7. **얼굴 처리** — 프레임 아웃 / 선글라스 / 폰 가림 / 모자 챙 / 크롭
8. **착장** — 상의·하의·신발 (소재까지 있으면 좋음)
9. **손 디테일** — 네일 종류, 반지 몇 개, 손목 액세서리
10. **무드 한 단어** — 시크 / 플레이풀 / 유머러스 / 다정한 / 힙한
11. **비율** — 3:4 세로 기본
12. **꼭 지켜야 할 것 / 절대 나오면 안 되는 것** — 가드레일로 변환됨
13. **레퍼런스 이미지 첨부 여부** — 있으면 "첨부 이미지와 동일하게 재현" 문장 추가

## 6. 작업 워크플로우

1. 위 질문 세트로 입력을 받는다 (부분 답변 허용).
2. 빈칸을 기본값으로 채워 **12블록 순서대로** 초안을 쓴다.
3. **가드레일 점검** — 이 장면에서 AI가 틀릴 만한 것을 찾아 해당 문장 뒤에 못 박는다.
   - 물건을 손에 쥐고 있나 → 하중·부양 가드레일
   - 로고·글자가 있나 → 정확한 문구 + "A가 아니라 반드시 B"
   - 반복 패턴(위빙, 펄프 몰딩, 니트 립)이 있나 → 형태 붕괴 가드레일
   - 거울·유리 반사인가 → 프레임 배제 가드레일
   - 제품이 있나 → 크기 비교 대상
4. **포인트 컬러가 3개 이상인지 확인**. 넘으면 줄인다.
5. **얼굴이 온전히 보이는지 확인**. 보이면 가리는 장치를 넣는다.
6. 생성 후 소품과 포즈를 손으로 고친다 (원작자 방식).
