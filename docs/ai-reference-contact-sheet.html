데이터 출처가 두 종류로 나뉩니다. 실측 배지가 붙은 유튜브 20개 채널은 Agent Reach가 설치한 yt-dlp로 채널 페이지를 직접 조회한 값입니다 — 구독자 수, 최근 12편의 조회수와 제목, 재생시간 모두 실제 값입니다. 미검증 배지의 인스타그램·스레드 9개 계정은 Agent Reach로 접근할 수 없어(본인 Chrome 로그인 세션이 필요) 큐레이션 기사 시점의 수치를 그대로 옮겼습니다.

기사 수치는 실제와 꽤 달랐습니다. 알린 ALINN 15.4만→18.1만, 일잘러 장피엠 10.9만→13.5만, 시민개발자 구씨 2.89만→5.73만처럼 대부분 늘었고 기묘한 자동화는 4.44만→4.23만으로 줄었습니다. 인스타·스레드 수치도 같은 정도로 어긋나 있을 가능성이 높으니, 기획 근거로 쓰기 전 실제 계정에서 확인하세요.
