# 핀터무드 이미지 프롬프트 생성

전체 원리·문형 사전·원문 색인은 `docs/image-prompt-system.md`에 있다. 세부가 필요하면 그 파일을 읽는다.

## 진행 방식

1. 아래 질문을 사용자에게 제시한다. **필수 4개만 답해도 진행한다.**
2. 빈칸은 맥락에 맞는 기본값으로 채운다 — 사용자에게 다시 묻지 않는다.
3. 12블록 순서대로 한글 프롬프트를 쓴다. 영문으로 쓰지 않는다.
4. 완성 후 체크리스트를 돌린다.

## 질문 세트

필수: ① 한 줄 시놉시스(누가/어디서/뭘 하나) ② 주력 소품·광고 제품 ③ 계절·시간·날씨 ④ 컬러 포인트 1~2개
선택: ⑤ 장소 ⑥ 시점 ⑦ 얼굴 처리 ⑧ 착장 ⑨ 손 디테일 ⑩ 무드 ⑪ 비율 ⑫ 금지사항 ⑬ 레퍼런스 첨부 여부

## 12블록 순서 (순서를 바꾸지 않는다)

1. 스펙 선언 `초고해상도 [계절] [장르] 사진, 3:4 세로 프레임.`
2. 시간·날씨·장소
3. 시점·화각
4. 크롭 — 무엇이 보이고 무엇이 프레임 밖인지 명시
5. 인물·포즈
6. 손 스펙 — `가늘고 긴 손가락의 곱고 흰 손, 매끄러운 피부, 짧고 깔끔한 자연 손톱` + 네일 + 반지 개수(숫자로) + 손목
7. 소품 배치 — 재질·형태 + 사물 간 관계 + 무심한 배치 동사(`반쯤 걸쳐`, `비스듬히 얹혔으며`, `아무렇게나 굴러`)
8. 물리 가드레일 — 해당 사물 문장 안에 붙인다
9. 의상 — 상의→하의→신발, 소재감 필수
10. 조명 — 광질·방향·무엇을 드러내는지·그림자 성격
11. 팔레트 — `팔레트는 [주조] 주조에 [포인트] 포인트, [보조] 보조, 중저채도.`
12. 클로징 — 반드시 `~ 무드.`로 끝

## 절대 규칙

- **얼굴은 온전히 보이면 안 된다.** 프레임 아웃 / 선글라스 / 폰 가림 / 모자 챙 / 턱 아래 크롭 중 하나를 반드시 쓴다.
- **채도 높은 포인트 컬러는 최대 2개.** 주조는 무채·뉴트럴 저채도.
- **개수는 숫자로 못 박는다** (반지 두세 개, 컵 4구) — 안 쓰면 AI가 남발한다.
- **제품에는 크기 비교 대상을 붙인다** — `폰의 가로 폭과 비슷한 립밤 크기`.
- **가드레일은 따로 몰아 쓰지 않고** 그 사물을 묘사하는 문장 뒤에 붙인다.
- 영문 병기 불필요. 한글로만 쓴다.

## 가드레일 카탈로그

| 상황 | 붙일 문장 |
|---|---|
| 손에 물건을 쥠 | `무게가 손바닥과 손가락 위에 물리적으로 자연스럽게 지지되어 어색한 부양이나 불가능한 겹침이 없다` |
| 물건이 걸려 있음 | `공중에 떠 있지 않고 [무엇]과 맞닿아 걸려 있다` |
| 로고·글자 | `[A]가 아니라 반드시 [B]` |
| 반복 패턴(위빙·펄프·니트) | `찌그러지거나 뒤틀리지 않은 반듯한 형태다` |
| 거울·유리 반사 | `프레임·테두리는 화면 어디에도 보이지 않고` |
| 형태 오답 가능 | `[오답] 금지` |
| 두 사물 크기 관계 | `[A]의 긴 변이 [B]의 긴 변과 평행하고 [A] 길이는 [B]보다 짧다` |
| 걷는 자세 | `자연스러운 자세지만 두 발 모두 발바닥이 지면에 닿아 있다` |

## 완성 후 체크리스트

- [ ] 얼굴이 가려졌나
- [ ] 포인트 컬러 2개 이하인가
- [ ] 12블록 순서대로인가
- [ ] `~ 무드.`로 끝나는가
- [ ] 이 장면에서 AI가 틀릴 만한 지점마다 가드레일이 붙었나
- [ ] 제품에 크기 비교 대상이 있나
- [ ] 개수가 숫자로 명시됐나
