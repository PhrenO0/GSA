# 참참참 vs Claude

웹캠으로 고개 방향을 인식하는 참참참 게임. **공격(참참참 외치기)은 Claude가 하고**, 플레이어는 고개를 돌려 피합니다.

## 실행

정적 파일이라 로컬 서버만 있으면 됩니다(웹캠은 `https` 또는 `localhost`에서만 동작).

```bash
cd chamchamcham
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 플레이 방법

1. **웹캠 시작** → 브라우저 카메라 권한 허용
2. **얼굴 정렬** → 3초간 정면 응시(정면 기준 위치를 학습)
3. **게임 시작** → "참! 참! 참!" 마지막 박자에 Claude가 좌/우를 가리킴
   - 같은 방향 → 걸림(목숨 -1)
   - 반대 방향 → 성공
   - 안 돌리면 무효 라운드
4. 목숨 3개를 다 잃으면 게임 오버. 라운드가 갈수록 박자가 빨라집니다.

웹캠 인식이 어려운 환경(조명/카메라 없음)에서는 **키보드 모드(← →)** 로 그대로 플레이할 수 있습니다.

## 동작 방식

- **얼굴 방향 인식**: 외부 라이브러리 없이, 캔버스로 축소한 프레임(160×120)을 YCbCr 스킨톤 필터로 걸러 얼굴 픽셀의 무게중심 x좌표를 구합니다. 캘리브레이션으로 저장한 정면 기준값과의 차이가 임계값(프레임 폭의 5.5% 또는 정면 흔들림의 2.2배 중 큰 값)을 넘으면 좌/우로 판정하고, 최근 5프레임 중앙값으로 흔들림을 억제합니다.
- **좌우 기준**: 분석 프레임을 좌우 반전해 그리므로 캔버스 좌표 = 거울 화면 좌표 = **플레이어 기준 좌/우** 입니다.
- **Claude의 수 선택**: 1차 마르코프 예측 — 플레이어의 직전 선택 뒤에 어떤 방향이 많이 나왔는지 세어 그 지점을 찌릅니다. 22%는 무작위로 두어 완전히 결정적이지 않게 했습니다. 습관이 생기면 잡힙니다.
- **동시 판정**: 마지막 "참!" 시점의 방향을 즉시 고정한 뒤 공격 방향을 공개하므로, 보고 나서 피할 수 없습니다.
