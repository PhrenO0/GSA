# 참참참 vs Claude

웹캠으로 고개 방향을 인식하는 참참참 게임. **공격(참참참 외치기)은 Claude가 하고**, 플레이어는 고개를 돌려 피합니다.

## 실행

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

`standalone.html` 은 위 세 파일을 한 파일로 합친 것이라 서버 없이 브라우저로 바로 열어도 됩니다. 다만 `file://` 에서는 카메라 권한이 브라우저마다 다르니(사파리는 차단), 잘 안 되면 위 서버 방식으로 여세요.

## 플레이 방법

1. **웹캠 시작** — 카메라 권한 허용
2. **고개 인식 학습** — 정면 · 왼쪽 · 오른쪽 세 자세를 각각 3초 카운트 뒤 측정합니다. **게임에서 실제로 할 동작 그대로** 해주세요
3. 게이지 바늘이 고개를 따라 움직이는지 확인
4. **게임 시작** — "참! 참! 참!" 마지막 박자에 Claude가 가리키는 반대쪽으로 고개를 돌리면 성공

목숨 3개를 잃으면 게임 오버. 라운드마다 박자가 빨라집니다(820ms → 430ms). 카메라가 없거나 막히면 **키보드 모드(← →)** 로 그대로 플레이할 수 있습니다.

## 인식 방식

외부 라이브러리 없이 캔버스만 씁니다.

1. 프레임을 160×120으로 줄이고 **좌우 반전**해 그립니다. 캔버스 좌표 = 거울 화면 좌표 = 플레이어 기준 좌/우.
2. YCbCr 스킨톤 필터로 얼굴 픽셀을 고르고 **무게중심 x** 를 구합니다. 최근 5프레임 중앙값으로 흔들림을 억제합니다.
3. 고개를 *회전*하면 머리 실루엣은 제자리라도 보이는 살색 영역이 한쪽으로 쏠리므로 이 무게중심이 움직입니다. 이동이든 회전이든 신호는 같은 스칼라 하나입니다.
4. 그 신호의 **부호와 크기는 사람·카메라·조명마다 달라서 고정하지 않습니다.** 대신 정면·왼쪽·오른쪽 세 자세를 실제로 측정해 기준값으로 삼고, 현재 값이 각 기준값 쪽으로 얼마나 진행했는지(감도 슬라이더로 조절)로 판정합니다.

> 초기 버전은 얼굴의 **평행 이동**만 봤기 때문에, 제자리에서 고개만 돌리는 실제 참참참 동작을 거의 잡지 못했습니다. 3단계 학습 방식은 그 문제를 해결하려고 도입했습니다.

## Claude의 수 선택

1차 마르코프 예측 — 플레이어의 직전 선택 뒤에 어떤 방향이 많이 나왔는지 세어 그 지점을 찌릅니다. 22%는 무작위로 두어 완전히 결정적이지 않게 했습니다. 마지막 "참!" 시점의 방향을 먼저 고정한 뒤 공격을 공개하므로, 보고 나서 피할 수는 없습니다.
